# Agent instructions

This repository is developed fully in the open, including agent-driven commit history. Everything committed here is public.

- Never commit or reference environment-specific information: real usernames, hostnames, local filesystem paths, IP addresses, environment variable values, credentials, tokens, or infrastructure details. Before committing, review the staged diff for such leaks.
- Commit messages, PRs, and documentation describe changes on their own terms: no internal tracker references, no planning narrative, no session context.
- Documentation describes the system as it is: present tense, no history or future promises outside roadmap documents.
- Project planning and design discussion live outside this repository. Do not create planning or discussion documents here.
