# Zero-width joiner content

A family emoji built from four scalars joined by ZWJ: 👨‍👩‍👧‍👦.

A profession sequence: 👩‍🔬 is woman scientist.

A flag sequence with ZWJ: 🏳️‍🌈 is the rainbow flag.

A ZWJ between plain letters: ab‍cd renders as four letters with an
invisible joiner that byte-level tooling must preserve.

A zero-width non-joiner for contrast: ab‌cd.
