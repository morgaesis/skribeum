# Footnotes

A claim that needs support.[^1] Another claim with a named note.[^harbor]

Two references in one sentence[^1][^harbor] reuse existing definitions.

An inline footnote^[written directly in the sentence body] needs no definition.

A footnote inside a blockquote:

> The quoted material also cites something.[^quoted]

## Definitions

[^1]: The first footnote definition, a single line.

[^harbor]: A named footnote definition
    whose second line is indented to continue the note.

    A second paragraph inside the same footnote definition.

[^quoted]: Definition for the reference made inside the quote.

[^orphan]: A definition that nothing references.

A reference to a missing definition[^missing] stays unresolved.
