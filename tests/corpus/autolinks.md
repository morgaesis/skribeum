# Autolinks

An angle-bracket autolink <https://example.com/angle> in a sentence.

A mail autolink <mailbox@example.com> in angle brackets.

An explicit mailto autolink <mailto:mailbox@example.com> with the scheme.

A bare URL https://example.com/bare that GFM-style autolinking may catch.

A bare www form www.example.com/no-scheme without a scheme.

An autolink with query parameters <https://example.com/search?q=corpus&page=2>.

A non-link in angle brackets <not a url at all> stays plain text.

An autolink inside emphasis: *see <https://example.com/emphasized> here*.

An autolink inside a blockquote:

> Reference material at <https://example.com/quoted-link> supports the claim.
