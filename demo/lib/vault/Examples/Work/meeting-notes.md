# Cedar Room working session

**Participants:** Mina, Arun, Jules
**Purpose:** Choose a test layout for the first public workshop

## Context

The team reviewed the room observations from [[Examples/Research/interview-notes|visitor interviews]] and the capacity comparison in [[Features/tables|Tables]]. The central tension is between fitting more seats and preserving a clear, quiet route along the windows.

## Discussion

Mina proposed three clusters of four chairs, with one cluster removed when a participant needs additional turning space. Arun noted that movable chairs also let facilitators shift between discussion and hands-on work without resetting the entire room.

Jules tested the route from the entrance to the nearest table. The direct path works if bags and spare materials stay on the storage wall. A low shelf near the door would create a pinch point, so that shelf is out of scope for the first layout.

The welcome should explain where quiet seating is located without asking anyone to disclose why they need it. Signs need to be readable from seated height and should use the same names as the spoken introduction.

> [!note] Working agreement
> Test the smallest useful session before adding equipment or furniture.

## Decisions

- Use twelve movable chairs for the first workshop.
- Keep the window-side route clear.
- Place materials on two smaller tables to reduce queuing.
- Record the durable layout choice in [[Examples/Work/decision-log|Decision log]].
