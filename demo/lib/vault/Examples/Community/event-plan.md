# Neighborhood repair cafe

## Purpose

Host a half-day gathering where neighbors can learn simple repair skills, work alongside one another, and decide when an item needs professional attention. The event focuses on small household objects, textiles, and basic bicycle adjustments.

## Room layout

| Zone | Lead role | Core equipment |
| --- | --- | --- |
| Welcome table | Greeter | Sign-in sheet, labels, safety card |
| Small objects | Repair guide | Hand tools, trays, task lights |
| Textiles | Sewing guide | Needles, thread, spare fabric |
| Bicycles | Cycle guide | Floor pump, tire levers, work stand |
| Waiting area | Floater | Chairs, water, project cards |

The shared-tool-table result in [[Features/tables|Tables]] suggests splitting common supplies between the object and bicycle zones. Clear labels should match the spoken orientation, following the access notes from [[Examples/Research/interview-notes|Interview notes]].

A bicycle station from another repair cafe, for scale: a stand, a floor pump within reach, and enough space to kneel beside the wheel.

## Volunteer briefing

- Begin by asking what outcome the visitor wants.
- Explain any risk before opening or disassembling an item.
- Keep removed parts in a labeled tray.
- Stop when the repair requires mains electricity, structural work, or specialist certification.
- Record unfinished work in plain language so the visitor knows the next step.

## Before opening

- [ ] Confirm six lead and support volunteers
- [ ] Mark a clear route between entrance and waiting area
- [ ] Prepare labels in large and standard type
- [ ] Test the bicycle stand on the floor surface
- [ ] Put the weather fallback on the entrance sign

> [!warning] Scope
> Volunteers demonstrate low-risk repairs. They do not inspect or certify safety-critical equipment.

## After the event

Count completed, referred, and unfinished items. Collect one sentence from each station about the most common missing tool or instruction. Feed useful patterns back into [[Examples/Work/project-ideas|Project ideas]].
