# Wikilinks in all four Obsidian forms

## Bare note link

A sentence linking to [[garden-journal]] by note name.

## Aliased link

A sentence linking to [[garden-journal|the garden notes]] with display text.

## Heading link

A sentence linking to [[garden-journal#Spring planting]] by heading.

## Block reference link

A sentence linking to [[garden-journal#^row-seven]] by block identifier.

## Combined forms

An aliased heading link [[garden-journal#Spring planting|planting section]] in prose.
An aliased block link [[garden-journal#^row-seven|row seven]] in prose.

## Edge shapes

A link with spaces in the target: [[weekly review notes]].
A link with a path-like target: [[projects/greenhouse/frame]].
A self-heading link with no note name: [[#Bare note link]].
Two adjacent links [[first-target]][[second-target]] with no separator.
A link inside emphasis *around [[emphasized-target]] text*.
An escaped non-link \[\[not-a-wikilink\]\] stays literal.
A wikilink inside a heading follows.
