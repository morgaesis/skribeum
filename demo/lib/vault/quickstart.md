# Quickstart

Welcome to the Skribeum demo vault. This tour takes a few minutes and uses real notes, links, and editing patterns rather than placeholder text.

## 1. Look around

Use the file tree to expand **Features** and **Examples**. Open [[index|Index]] for a compact map of the vault, then return here through a wikilink or the note switcher.

Open the command surface with `mod+k`. Search for `cedar` to find notes by name, or enter `?cedar` to search note text across the vault. The results include [[Examples/Work/meeting-notes|meeting notes]] and [[Examples/Work/decision-log|a decision record]].

## 2. Edit a note

Add a sentence below this paragraph, format a phrase, or insert a task. The change remains available while this page is open, so moving between notes does not discard it. Reloading the page restores the seeded vault.

## 3. Explore rich syntax

- Follow [[Features/wikilinks|Wikilinks]] to see links with aliases, headings, and nested paths.
- Open [[Features/embeds|Embeds]] for transclusion examples.
- Compare [[Features/inline-math|Inline math]] with [[Features/block-math|Block math]].
- View [[Features/mermaid-diagram|Mermaid diagram]] for a rendered flow.
- Inspect [[Features/frontmatter|Frontmatter]] and its properties.
- Open [[Features/showcase|Showcase]] for one note that combines most of the above.
- Open `demo.canvas` from the file tree for a visual overview. This browser demo shows the canvas read-only; the desktop app allows moving and editing cards.

## 4. Use navigation tools

Open [[Examples/Research/literature-review|Literature review]], then use document find for `daylight`. Check the outline to jump between its nine sections. Global search can locate terms across the whole vault, while document find stays within the open note.

## 5. Make the demo yours

Mark one item complete in [[Features/tasks|Tasks]], add a row to [[Features/tables|Tables]], and change a setting. Settings use browser storage, while note edits use memory only.

> [!tip] Suggested final stop
> Open [[Examples/Personal/weekly-review|Weekly review]] to see links, tasks, tags, and callouts working together in a natural note.
