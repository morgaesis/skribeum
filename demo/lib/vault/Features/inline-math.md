# Inline math

Inline math keeps a compact expression inside a sentence. It is useful when the formula is part of the explanation rather than the main object on the page.

For a rectangular planting bed, the area is $A = w \times l$. A bed that is $1.2\,\text{m}$ wide and $3\,\text{m}$ long has an area of $3.6\,\text{m}^2$.

A simple average can be written as $\bar{x} = \frac{1}{n}\sum_{i=1}^{n}x_i$. In the [[Examples/Research/interview-notes|interview notes]], that average could summarize a rating, but the individual comments would still preserve important context.

For a more prominent derivation, use a display expression as shown in [[Features/block-math|Block math]].
