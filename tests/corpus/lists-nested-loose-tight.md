# Lists

## Tight unordered list

- Cedar shavings for the workshop floor
- Beech dowels sorted by width
- Ash offcuts kept for kindling

## Loose unordered list

- First loose item stands alone.

- Second loose item follows a blank line.

- Third loose item ends the list.

## Tight ordered list

1. Measure the plank twice
2. Mark the cut line
3. Saw along the mark

## Ordered list with alternate delimiter and offset start

7) Seventh position starts this list
8) Eighth position continues it
9) Ninth position closes it

## Nested mixed list

1. Outer ordered item one
   - Inner bullet under item one
   - Second inner bullet
     1. Deep ordered item
     2. Another deep ordered item
2. Outer ordered item two
   - Inner bullet under item two

## Loose nested list with paragraphs

- Outer item with a following paragraph.

  This paragraph belongs to the first outer item.

  - Nested item inside the loose parent

- Second outer item after the nested block.
