# Tables

Tables are useful when each item shares the same attributes. Prose remains better for nuance and explanation.

Click a rendered cell to edit it in place. Arrow keys move within and between cells, Tab moves to the next cell, Shift+Tab moves to the previous cell, and Enter moves down the current column. Tab or Enter at the table boundary appends a row. Escape returns to the note after the table.

Table structure commands in the command surface and More actions menu insert or delete the focused row or column. The bottom and right insertion strips append a row or column with a pointer. Use `Table: edit source` or `mod+e` when you need the pipe-delimited Markdown.
