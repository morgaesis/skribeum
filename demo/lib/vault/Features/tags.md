# Tags

Tags group notes by theme, status, or working context. A small vocabulary is easier to maintain than a tag for every passing thought.

## Examples

- #project/cedar-room identifies work related to the fictional community workspace.
- #practice/review marks notes used in a recurring reflection habit.
- #context/outdoors connects the [[Examples/Personal/garden-log|garden log]] and [[Examples/Personal/travel-plan|travel plan]].
- #status/active distinguishes material that still needs attention.

Tags can sit inside prose when that placement reads naturally. The repair cafe remains #status/active until volunteer roles and the venue layout are confirmed.

## Working convention

Use links when a concept deserves its own note and tags when several notes need a lightweight shared label. The [[index|vault index]] uses links because its destinations are specific notes. A search for `#project/cedar-room` gathers several notes without requiring a separate index entry for every connection.
