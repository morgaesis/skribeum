# Embeds

An embed references another note while keeping the source relationship visible. It is useful for assembling dashboards, briefings, and recurring reviews from smaller notes.

## A practical pattern

A weekly hub can embed active tasks from project notes while those tasks remain owned by their original context. This avoids copying text into several places and wondering which copy is authoritative.

The [[Examples/Personal/weekly-review|weekly review]] uses ordinary links instead, which is often better when the reader needs a compact summary. Embeds and links serve different reading rhythms.
