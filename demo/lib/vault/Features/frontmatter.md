# Frontmatter

Frontmatter stores structured properties at the beginning of a Markdown note. The delimiters and key-value pairs remain plain text, while the editor can present them as note properties.

This note includes a title, an alias, two tags, a status, a numeric rating, and a boolean value. These fields demonstrate several common value shapes without depending on a private workflow.

## A restrained approach

Metadata is most useful when it supports a real retrieval need. A `status` field may help separate active work from reference material. An alias may make a note easier to find. Fields that nobody filters, sorts, or reads add maintenance cost without improving the note.
