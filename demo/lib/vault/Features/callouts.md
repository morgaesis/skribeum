# Callouts

Callouts set supporting information apart from the main flow. The marker after the exclamation point controls the visual treatment.

> [!note] Context
> The Cedar Room examples describe a fictional project created for this demo.

> [!tip] Editing habit
> Give a callout a specific title when readers may scan the page rather than read it in order.

> [!warning] Keep the source nearby
> A highlighted conclusion still needs a link to the note that contains its evidence.

> [!question] Open question
> Which decisions belong in [[Examples/Work/decision-log|the decision log]], and which can stay in meeting notes?

> [!success] Small win
> The first interview round produced a concrete accessibility checklist.

Callouts work best when they clarify structure. If every paragraph is highlighted, none of them feels important.
