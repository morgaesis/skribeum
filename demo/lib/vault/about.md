# About this vault

This sample vault is a small, connected notebook for exploring the Skribeum editor surface. Every note is original demo material. The people, projects, and events are fictional, but the writing follows the shape of notes someone might keep during ordinary work and life.

The vault is organized around two kinds of material:

- **Features** contains focused demonstrations of Markdown and Obsidian-style syntax.
- **Examples** contains longer working notes that combine those features in context.

Start with [[quickstart|the guided tour]], or use [[index|the vault index]] as a map. The canvas at `demo.canvas` collects a few of the example notes into a visual project overview.

## A useful editing loop

Good notes tend to move through a simple cycle: capture an observation, connect it to something that already exists, and return later to refine it. This vault models that rhythm. The [[Examples/Work/meeting-notes|meeting notes]] produce tasks, the [[Examples/Work/decision-log|decision log]] records durable conclusions, and the [[Examples/Personal/weekly-review|weekly review]] ties loose ends together.

> [!note] Browser demo
> Changes in this vault live in memory for the current page session. Reloading restores the original sample content.
